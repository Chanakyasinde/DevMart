# ShopEase

**ShopEase** is a full-stack e-commerce web application designed to simulate a real-world online shopping platform.

Users can:
- Browse products  
- View product details  
- Add items to cart  
- Place orders  

The project extends beyond development by integrating **DevOps practices such as containerization, cloud deployment, and CI/CD automation**.

---

## 🎯 Objectives

- Build a complete full-stack web application  
- Apply **Software Development Life Cycle (SDLC)**  
- Integrate frontend, backend, and database  
- Implement authentication and core e-commerce features  
- Use **Docker & Kubernetes** for deployment  
- Deploy application using **AWS cloud services**  
- Automate workflows using **Bash scripting**  
- Implement **CI/CD pipeline** for continuous integration and deployment  

---

## 🔄 SDLC Approach

The project follows a structured SDLC model:

1. **Planning** – Define requirements and features  
2. **Design** – System architecture and API design  
3. **Development** – Frontend and backend implementation  
4. **Testing** – Unit and API testing  
5. **Deployment** – Docker, Kubernetes, AWS  
6. **Maintenance** – Improvements and updates  

---

## 🛠️ Technology Stack

### Frontend
- React (Vite)
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

---

## ⚙️ DevOps & Tools

- **Docker** – Application containerization  
- **Kubernetes** – Container orchestration  
- **AWS** – Cloud deployment (EC2, S3)  
- **Bash Scripting** – Automation of build & deployment  
- **GitHub Actions** – CI/CD pipeline  

---

## 📂 High-Level Architecture

- Frontend communicates with backend via REST APIs  
- Backend handles business logic and database operations  
- Docker containers package services  
- Kubernetes manages deployment  
- AWS hosts the application

- A fully functional e-commerce web application
